# Vizuzik

Application Android plein écran affichant la lecture en cours sur Deezer (pochette, titre, artiste) avec les contrôles précédent / lecture-pause / suivant.

L'app lit la session multimédia de Deezer via l'API Android de notification listener : au premier lancement, elle demande d'autoriser l'accès aux notifications (Réglages > Accès aux notifications) pour pouvoir afficher et contrôler la lecture.
